# Билим Нуру — сайт учебного центра

Полный проект: лендинг (React + TypeScript) и API (NestJS + MongoDB) с админ-панелью.

## Структура проекта

```
bilim-nuru/
├── backend/     — NestJS API + MongoDB (Mongoose)
└── frontend/    — React + TypeScript (Vite), включая /admin панель
```

## Возможности

- Разделы лендинга: Начало, О нас, Курсы, Блоги, Преподаватели, Отзывы, Контакты, шапка и подвал сайта — карусели курсов/блогов/преподавателей/отзывов на Swiper.js
- Переключение языка интерфейса: **KG (по умолчанию) / RUS / UZB / EN** — переводится меню, кнопки, подписи форм, а также сама админ-панель. Сам контент (курсы, блоги, преподаватели) хранится в одном варианте, как вы его вводите в админке.
- Два филиала с переключателем на странице "Контакты" — у каждого свой адрес, телефон, часы работы и своя карта Yandex (вставляется как iframe)
- Загрузка изображений файлом (не по ссылке) — фото курсов, преподавателей, блогов и блока "О нас" загружаются прямо из админки и хранятся в MongoDB
- Форма "Оставить отзыв" — отзыв уходит на модерацию и появляется на сайте только после одобрения администратором
- Форма заявки в контактах — сохраняется в MongoDB, видна в админ-панели
- Простая админ-панель (`/admin`) с логином: управление курсами, блогами, преподавателями, отзывами (модерация), заявками, филиалами, блоком "О нас" и общими настройками сайта (телефон, соцсети и т.д.)

## 1. Установка MongoDB

Нужна работающая MongoDB (локально или облачная, например MongoDB Atlas — бесплатный тариф подходит).

- Локально: скачайте с https://www.mongodb.com/try/download/community и запустите (`mongod`)
- Или создайте бесплатный кластер на https://www.mongodb.com/cloud/atlas и скопируйте connection string (вида `mongodb+srv://...`)

## 2. Backend (NestJS)

```bash
cd backend
cp .env.example .env
```

Откройте `.env` и укажите:
```
MONGO_URI=mongodb://localhost:27017/bilim-nuru   # или ваш Atlas connection string
JWT_SECRET=любая_длинная_случайная_строка
ADMIN_USERNAME=admin
ADMIN_PASSWORD=придумайте_надёжный_пароль
FRONTEND_URL=http://localhost:5173
```

Установите зависимости и создайте первого администратора:

```bash
npm install
npm run seed:admin
```

Запуск в режиме разработки:

```bash
npm run start:dev
```

API будет доступно на `http://localhost:4000/api`.

Для продакшена:
```bash
npm run build
npm run start:prod
```

## 3. Frontend (React)

```bash
cd frontend
cp .env.example .env
```

В `.env` укажите адрес вашего backend API:
```
VITE_API_URL=http://localhost:4000/api
```

Установка и запуск:

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:5173`.

Сборка для продакшена (папка `dist/` — загрузите её содержимое на любой хостинг):
```bash
npm run build
```

## 4. Первый вход в админ-панель

Откройте `http://localhost:5173/admin/login` и войдите с логином/паролем из `.env` backend (`ADMIN_USERNAME` / `ADMIN_PASSWORD`).

После входа заполните по порядку:
1. **О нас** — заголовок, текст, фото, цифры (студенты/курсы/преподаватели/годы)
2. **Настройки сайта** — телефон, email, соцсети — это выводится в шапке и подвале
3. **Филиалы** — добавьте 2 филиала. Для карты: на Яндекс.Картах найдите нужный адрес → «Поделиться» → «Код для сайта» → скопируйте значение `src` из тега `<iframe>` и вставьте в поле "Yandex Map iframe"
4. **Курсы**, **Преподаватели**, **Блоги** — добавьте свой контент
5. **Отзывы** — здесь будут появляться отзывы с сайта на модерации; одобряйте нужные
6. **Заявки** — сюда попадают все заявки с формы "Контакты"

## Технологии

- **Backend:** NestJS, MongoDB/Mongoose, JWT-аутентификация, class-validator
- **Frontend:** React 18, TypeScript, Vite, React Router, react-i18next (мультиязычность интерфейса), Axios

## Примечания по безопасности перед публикацией сайта

- Обязательно смените `JWT_SECRET` и `ADMIN_PASSWORD` в `.env` на свои собственные значения
- Не публикуйте файл `.env` (он уже добавлен в `.gitignore`)
- Настройте HTTPS на вашем хостинге/домене
